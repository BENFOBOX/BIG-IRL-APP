# BIG IRL APP
A new Android IRL streaming alpha. It contains an original Compose interface and no Brix application code, screens, tests, artwork, or branding.

Current milestone: camera/microphone, 720p30 H.264/AAC, direct RTMP/RTMPS or SRT through RootEncoder, and Wi-Fi/cellular status. Next: standard SRT to the home Jetson, then an original multipath sender/receiver.
